# Утилиты vt_cat и vt_grep

Данный проект был выполнен в рамках углубленного изучения языка С и операционных систем семейства *nix. Целью данного проекта являлось написание собственных утилит, которые повторяют функционал утилит cat и grep с поддержкой определенных флагов.

Утилита vt_cat поддерживает следующие флаги:

| Флаг | Описание |
| ---- | -------- |
| -b (GNU: --number-nonblank) | нумерует только непустые строки |
| -e предполагает и -v (GNU only: -E то же самое, но без применения -v) | также отображает символы конца строки как $ |
| -n (GNU: --number) | нумерует все выходные строки |
| -s (GNU: --squeeze-blank)	| сжимает несколько смежных пустых строк |
|-t предполагает и -v (GNU: -T то же самое, но без применения -v) | также отображает табы как ^I|

Список поддерживаемых флагов утилитой vt_grep:

| Флаг | Описание |
| ---- | -------- |
| -e | Шаблон |
| -i | Игнорирует различия регистра. |
| -v | Инвертирует смысл поиска соответствий |
| -c | Выводит только количество совпадающих строк |
| -l | Выводит только совпадающие файлы |
| -n | Предваряет каждую строку вывода номером строки из файла ввода |
| -h | Выводит совпадающие строки, не предваряя их именами файлов |
| -s | Подавляет сообщения об ошибках о несуществующих или нечитаемых файлах |

## Запуск и установка проекта

Для использования проекта на вашем устройстве должен быть установлен компилятор gcc и утилита make.

После этого вы смело можете клонировать проект на своё устройства, при условии, что вы добавили SSH ключ устройства в ваш профиль на Gitlab.

```bash
git clone git@gitlab.com:v_tarykin/cat_and_grep_utils.git
```

Для использования утилиты vt_cat необходимо выполнить следующие команды: 

```bash
cd cat_and_grep_utils/src/cat
make
```
После этих действий у вас должен появиться исполняемый файл с названием vt_cat. Теперь вы можете пользоваться утилитой.

Аналогичные действие делаются и по отношению к vt_grep, только для этого вам будет необходимо перейти в директорию grep, которая также находится в директории src:

```bash
cd cat_and_grep_utils/src/grep
make
```

## Использование

Для использования утилит, если они не были установлены, стоит перед названием исполнительного файла написать "./", после названия самого файла через пробел указать полное название файла, который вы желаете обработать:

```bash
./vt_сat test.txt
```
Флаги указываются, как в любых других утилитах оболочки bash, через одиночное тире, в случае коротких флагов:

```bash
./vt_сat -n test.txt
```

или же с двумя тире, в случае полных названий флагов, адаптированных под GNU:

```bash
./vt_сat --number test.txt
```
В случае утилиты grep, после названия исполняемого файла и, при наличии, флагов стоит указывать шаблон, по которому будет осуществляться поиск совпадающих строк:

```bash
./vt_grep -i U test.txt
```
